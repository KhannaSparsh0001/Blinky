# MS Paint Navigation Guide

## App Overview
- **Process**: `mspaint.exe`
- **Window Title**: `untitled - paint`
- **Purpose**: Basic 2D raster graphics editor for drawing, creating, and editing images.

## Standard Behaviors
- Opens with a blank canvas by default.
- Supports basic file operations (New, Open, Save).
- Provides a toolbar with drawing tools (pencil, brush, eraser, fill, etc.).
- Modern versions may include AI-powered tools for image enhancement.

## Navigation & Shortcuts

### File Operations
- **New File**: `Ctrl + N`
- **Open File**: `Ctrl + O`
- **Save File**: `Ctrl + S`
- **Close Window**: `Ctrl + F4`

### Common Menus & Actions
- **File Menu**: Access via the top-left menu or `File` tab for save/open options.
- **Home Tab**: Contains primary drawing tools and color palettes.
- **View Tab**: Adjust zoom level and grid visibility.
- **Help/Support**: 
  - In modern Windows versions, click the `?` icon or go to `File > Help`.
  - Note: Legacy tutorials may be outdated; refer to Microsoft's official "Draw, Create and Edit with Paint" guide for current features.

## Tips for Blinky
- Use `Ctrl + Z` to undo mistakes.
- Use `Ctrl + A` to select the entire canvas.
- If the window title shows "untitled", the file has not been saved yet.
