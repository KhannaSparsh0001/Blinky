# Telegram Desktop Navigation Guide

## App Overview
- **Process**: `telegram.exe`
- **Window Title**: `telegram (38641)`
- **Type**: Instant Messaging & VoIP Application

## Standard Behaviors
- **Startup**: Opens to the last active chat or the main chat list.
- **Search**: Global search bar at the top allows searching for messages, users, and files.
- **Notifications**: System tray icon indicates unread messages; clicking it opens the app.
- **Multi-window**: Supports multiple windows for different accounts or chats.

## Navigation Paths

### Main Interface
- **Chat List**: Left sidebar displays all conversations. Click a chat to view messages.
- **Message Pane**: Central area for viewing and sending messages.
- **Right Sidebar**: Context-dependent (e.g., chat info, media, files, or settings).

### Accessing Settings
1. Click the **Hamburger Menu** (☰) in the top-left corner.
2. Select **Settings** from the dropdown.
   - *Alternative*: Press `Ctrl + ,` (if enabled) or right-click the tray icon > Settings.

### Accessing Help & Support
1. Click the **Hamburger Menu** (☰) in the top-left corner.
2. Select **Help** or **FAQ**.
   - *Alternative*: Look for a **Question Mark (?)** icon in the bottom-left corner of the main window.

### Common Shortcuts
- `Ctrl + F`: Search within the current chat.
- `Ctrl + N`: New chat.
- `Ctrl + W`: Close current chat window.
- `Alt + Tab`: Switch between open Telegram windows.
