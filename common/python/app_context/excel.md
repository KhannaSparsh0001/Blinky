# Excel Navigation Guide

## Standard Behaviors
- **Cell Navigation**: Use Arrow Keys to move between cells. Hold `Shift` + Arrow Keys to select a range of cells.
- **Formula Bar**: `Backspace` deletes one character to the left or clears the entire content of the Formula Bar.
- **Window Control**: `Alt` + `Spacebar` opens the Control menu for the Excel window (Minimize, Maximize, Close).

## Navigation & Shortcuts
- **Help/Support**: Press `F1` or click the white question mark (`?`) at the top right of the Ribbon to access online Help.
- **Name Box**: Press `F3` to open the Name Box dialog to select or define a named range.
- **General Access**: The Ribbon menu at the top contains all primary commands (File, Home, Insert, etc.).
