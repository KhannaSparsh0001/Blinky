# Raycast Navigation Guide

## Standard Behaviors
- **Primary Interface**: Raycast operates as a command palette. It is typically invoked via a global hotkey (default is often `Cmd + Space` on Mac or `Alt + Space` on Windows, though configurable).
- **Search-First**: The main view is a search bar. Typing filters commands, apps, files, and snippets.
- **Modal Window**: The window is modal and usually closes when focus is lost or `Esc` is pressed.

## Navigation & Shortcuts

### General Navigation
- **`Esc`**: Go back to the previous view. From the root search, closes the Raycast window.
- **`Shift + Esc`** (Windows) / **`Cmd + Esc`** (Mac): Pop to Root (return to the main search bar from any sub-view).
- **`Ctrl + W`** (Windows) / **`Cmd + W`** (Mac): Close the current window/tab.

### Accessing Settings
1. Type `Settings` in the main search bar.
2. Select **Settings** from the results.
3. Navigate tabs:
   - **Shortcuts**: View and assign hotkeys for all commands.
   - **General**: Configure launch behavior, appearance, and system integration.

### System Commands & Window Management
- **System Commands**: Use Raycast to execute OS-level actions (e.g., lock screen, sleep, volume control) without digging through OS menus.
- **Window Management**: 
  - On Windows, supports virtual desktop management (e.g., auto-close empty desktops).
  - On macOS, can override system shortcuts for window snapping and space management.

### Help & Support
- Type `Help` or `Support` in the search bar to access documentation or contact support.
- Check the **Settings** > **About** section for version info and update status.
